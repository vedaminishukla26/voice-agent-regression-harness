# duplex-harness

*(provisional name — will be renamed once the plan is settled)*

A regression harness for real-time voice agents: drive a simulated speaker through a
real audio path into a live agent, capture both sides with timing, and gate behaviour
and latency in CI.

## Status

Scaffolding only. No implementation yet — awaiting the detailed plan.

## What this is not

This is a personal project. It is not affiliated with, does not depend on, and never
writes to any employer system. It contains no proprietary prompt, rubric, question
bank, or candidate data. It is designed to run against **any** LiveKit or Pipecat
agent, not a particular one.

See [INFRA.md](INFRA.md) for the infrastructure and traceability rules, which are
enforced for every dependency and service this project touches.
